# Retail-Insights-Customer-Product-Campaign-Analysis
A data-driven retail analytics project evaluating sales performance, customer and product behavior, and the impact of a trial campaign across selected stores using Python, Excel, and Power BI.

## Project Objectives 🎯
- Evaluate overall sales, customer, and transaction performance.
- Analyze customer segments and life stages.
- Identify high-performing brands and products.
- Evaluate the impact of the trial campaign across selected stores.
- Compare trial stores with control stores.
- Generate data-driven insights and recommendations.
  
# Tools 🛠️
- Python
- Excel
- Power BI
- Statistical Analysis
  
# Key Findings 📊
1. Total Sales: $1.93M
2. Transactions: 264,836
3. Unique Customers: 72,637
4. Average Transaction Value: $7.30
5. Top Customer Segment: Mainstream
6. Top Brand: Kettle
7. Best Performing Trial Store: Store 88
8. Store 88 Sales Increase: 217.03%

## Key Insight 🔍
The trial campaign produced different results across stores, indicating that campaign effectiveness may depend on store-specific characteristics and context.
Store 88 showed the strongest performance, while Store 77 experienced a significant decline.

## Recommendations ✉️
The findings support a selective expansion strategy, with further analysis of the factors behind Store 88's success and Store 77's decline before broader campaign implementation
